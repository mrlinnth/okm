### Task [3.2]: Add server modal [DONE]

#### Subtasks

- [ ] daisyUI modal (matching Classic key manager's modal conventions):
      label field, optional public host field, server JSON textarea.
- [ ] Client-side loose validation before submit (parseable JSON, `apiUrl`
      starts with `https://`), inline error on failure — same UX as Classic
      key manager's Connect validation.
- [ ] On submit, `fetch('/servers', {method: 'POST', body: JSON.stringify
({label, serverJson, publicHost})})`. On success, append the returned
      server to `servers` and close the modal. On a 422 response, show the
      specific error message inline without closing the modal (validation
      vs. unreachable-server messages must both surface distinctly, per
      requirements).

#### Key Files

- `app/Views/servers/index.blade.php`

#### Verification

Manually add a server via the UI with a real/test Outline server JSON,
confirm the card appears; retry with invalid JSON and with an unreachable
`apiUrl` and confirm each shows its own distinct inline error.
