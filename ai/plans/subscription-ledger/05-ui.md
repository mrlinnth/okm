# Phase 5: Frontend UI

Depends on: Phases 1–4 (all `/subscriptions/*` endpoints working). Reuses
the Alpine.js/htmx layout wiring and daisyUI modal conventions established
in Classic key manager and Saved servers registry.

#### Subtasks

- [ ] Build `app/Views/subscriptions/index.blade.php` extending
      `layouts.master`, replacing the Phase 1 placeholder.
- [ ] Header + "New subscription" button; filter bar (recipient search,
      status select, saved-server select, "Expiring soon" checkbox) —
      matching `ai/prototype/blueprint.md` / `index.html`'s "Subscriptions"
      screen.

      Alpine-held `subscriptions` array), matching the prototype's

### Task [5.2]: New subscription modal and success panel

#### Subtasks

- [ ] daisyUI modal: recipient name, key name, active-server select
      (populated from the servers list passed by the controller), duration
      radio/select (1/2/3 months), optional notes.
- [ ] On submit, `fetch('/subscriptions', ...)` → on success, prepend the
      new record to `subscriptions` and open a success panel showing

### Task [5.3]: Row actions — copy, inline edits, kebab menu

#### Subtasks

- [ ] Copy button: copies `accessUrl`, "Copied!" for 1.5s.
- [ ] Recipient name and key name: click-to-edit inline (same interaction
      pattern as expiry — see Task 5.1's expiry handling below), per the
      Phase 2 UI note — saves via `POST /subscriptions/{id}` on
      change/blur.
- [ ] Expiry: click-to-edit → native date input → `POST
    /subscriptions/{id}/expiry` on change, saves immediately.
- [ ] Kebab menu: Extend (one click → `POST .../extend`, no modal),
      Enable/Disable (one click, label/badge flips immediately), Reroll key
      (one click → `POST .../reroll`, menu label flips to "New key issued"
      for 1.8s), Delete (daisyUI confirm modal → `POST .../delete`, remove
      row on success). Surface any `warning` field from Reroll's response
      as a non-blocking inline notice (per requirements — cleanup failures
      don't fail the operation but should be visible).

#### Key Files

- `app/Views/subscriptions/index.blade.php`

#### Verification

Manually exercise each action against a real subscription: extend (verify
new expiry), reroll (verify key changes, verify a warning surfaces if you
simulate a cleanup failure), enable/disable (verify key creation/removal),
delete (verify row removal and Outline key removal when active).
